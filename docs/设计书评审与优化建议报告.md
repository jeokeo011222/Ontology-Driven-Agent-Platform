## 1. 总体判断

**设计底子是好的。** 抽验确认了一批高质量决策，应予保留：

- ERP 彻底解耦 + Mock ERP 先行的契约策略（总书 §1.1/§8）
- 任务状态与业务状态分离、`UNKNOWN` 一等状态、禁止盲目重发（总书 §4.6/§7.3）
- 审批绑定具体操作参数摘要，参数变更即失效（总书 §5.5）
- 默认拒绝、三层 PEP、委托权限取交集不扩权（第三篇）
- 计划 DAG 化 + LLM 输出仅候选经 Compiler/Validator 校验（第六篇 §5）
- OWL 推理与 SHACL 验证分维度、不合并成"本体正确率"（总书 §9.3）
- 显式值状态机 PRESENT/MISSING/NULL/UNMAPPED/CONFLICT/STALE（第十二篇 §7.2）
- 评估四类数据集防泄漏 + 安全硬门禁零容忍（第十五篇）

**但这份设计书目前还不能直接进入编码**，存在三个系统性问题：

1. **分册之间没有收敛机制（最核心）**。同一概念在多个分册重复定义且互相矛盾——状态词表至少 9 套、计划体系 4 份、Registry 数据模型 2 套。这是文档工程的失败，不是设计的失败，但实现期会集中爆发。
2. **若干 P0 级正确性缺陷以"示例代码 / 公式"形态存在**。例如第六篇的状态转换函数只写了 happy path，照抄即审批死锁；第七篇的幂等键公式与同节原则相互矛盾。
3. **总书与分册已经漂移**。总书的 12 模块清单、开发顺序编号、阶段计划均成文于分册扩容之前，且无追溯矩阵。

## 4. 架构级优化建议

### 4.1 build vs buy：把重复造轮子的部分显式决策

| 领域 | 分册现状 | 成熟替代 | 建议 |
|---|---|---|---|
| 工作流编排 + DAG + Saga + 重试 | 第八/十篇全自研 | Temporal / Cadence | MVP 前评估 ADR；若自研，明确只保留 ERP 对账与治理差异化层 |
| Outbox / Inbox / 租约 / 延迟队列 | 第十篇全自研 | river（Go 原生）/ pgmq | 评估后可覆盖 P1-P3 大部分 |
| LLM 协议转换 / 路由 / 限流 / 熔断 / 缓存 | 第九篇全自研 | LiteLLM / Higress / Kong AI Gateway | 基础能力用开源承载；自研聚焦数据分级、预算、审计 |
| RDF 存储与推理 | 第十三篇自研 PG 三元组引擎 + 自研 CBO | 成熟 RDF Store + reasoner | Spike 对比后决策；自研 CBO 性价低，V1.0 降为规则式优化（选择性排序+下推 PG SQL） |

### 4.2 插件运行时路线一次性定型

默认**独立受控进程**（非 root + seccomp + cgroup）→ 容器为可选 Runner（写明 dockerd 受控接入方式）→ WASI 标注 V2 评估。第一篇 Compose 补 plugin runtime 拓扑与安全边界。Manifest 中 `runtime.type` 与之一一对应。

### 4.3 第十三篇存储选型前置为门禁

P2 启动前用 Medium 集（1000 万三元组）实测 PG 索引方案 vs 1-2 个成熟 RDF Store，输出选型报告作为进入 P2 的门禁。同时：PG 五索引在 1 亿三元组目标下写放大约 5 倍，建议按 tenant 声明式分区、索引精简为 PK+POS+OSP，或写明"PG 只承载 ≤1000 万级"并写入验收阈值。

### 4.4 第九篇治理闭环

补语义缓存三层（精确 digest → 语义 embedding → 本体规则）且命中回传 `cache_hit=true` 降权；补令牌桶参数表（端点×租户）与 429+Retry-After；补 tokenizer 版本管理与"供应商账单 vs usage_ledger"月度对账作业；结构化输出补"校验失败 → 受限重生成 ≤N 次 → OUTPUT_INVALID 终态"回路。

### 4.5 第六篇等待态与恢复

定义审批/输入的 `提醒 → 升级 → 自动拒绝` 链与 deadline 出口（过期前强制完成在途对账）；`REQUIRES_RECONCILIATION` 补调度领取路径与租约续期 API（当前 30s 租约无续期，长工具调用必掉租约）。

### 4.6 第七篇补偿命令域

Port 增加补偿/冲销/红字/撤回命令域，与原操作关联并同样过 Gateway/账本/审批——当前只谈幂等与对账，补偿整体缺席，而第六篇 §12.4 已承认补偿是一等操作。Mock 与真实 Adapter 的 T01-T12 契约套件定为 Adapter 准入门槛，漂移显式登记为 capability gap。
