# 财务域数据集

## 定位

存放财务域（报销、费用类别、凭证关系等）的**固定评估数据集**，用于第十五篇的
回归测试与质量门：同一数据集上的判断结果应随版本可重复。

## 收录规范

- 每个数据集一个子目录，至少含一份 `dataset.json`（与 `datasets/finance-demo/dataset.json` 同构）
  与说明其用例意图的 `README.md`。
- 数据集必须**固定**：一旦被某次发布引用，其内容不得原地修改，只能新增版本目录。
- 涉及人员与组织的数据使用虚构名称，不得包含真实个人信息。

## 当前状态

**可运行样例：`datasets/finance-demo/`**（含 agents / ontologies / plans / providers / runs / tools 六份 JSON）。

本目录用于存放**演示样例之外**的评估数据集，目前尚未落盘。

落地时需要（第十五篇）：数据集元信息、案例清单、期望判定，以及与质量门
（`release_mgmt` schema）的绑定关系。
