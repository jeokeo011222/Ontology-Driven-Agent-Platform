# 安全数据集

## 定位

存放安全测试的**攻击用例集**，供 `tests/security` 与持续回归使用
（第十六篇 §10.2「安全测试」）。

## 收录规范

按攻击面分组，每组一个子目录：

| 分组 | 覆盖内容 |
| --- | --- |
| `cross-tenant/` | 跨租户读取与写入尝试 |
| `object-scope/` | 对象越权（同租户内的范围越界） |
| `prompt-injection/` | 面向 Agent/LLM 的提示注入语料 |
| `tool-bypass/` | 绕过 Harness 直接触发工具的尝试 |
| `approval-tamper/` | 审批摘要篡改尝试 |
| `secret-leak/` | 诱导响应或日志泄露凭据的用例 |

每个用例必须写明：**期望结果**（拒绝方式与错误码）与**判据**（为什么这样算失败）。
仅记录"输入"而无"期望"的语料无法自动化，不收录。

## 当前状态

**目录已建立，语料尚未落盘。**

当前安全测试的机制性断言位于：

- `tests/security/security_test.go` —— 逐端点匿名拒绝矩阵、拒绝响应不泄露秘密、
  依赖未装配时不得返回 200；
- `tests/integration/tenant_isolation_test.go` —— 真实两租户 RLS 隔离比对。

上述断言是**机制层**的；本目录补充的是**语料层**（具体攻击载荷）。
两者互补：机制层保证防护存在，语料层保证防护有效。
